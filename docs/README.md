# Document Register

This register lists every controlled document of Ludus. Rules for controlled documents are
in the [Documentation Standard](standards/documentation-standard.md) (LUD-STD-004). The
document checker fails if a controlled document is missing from this register.

**Where to start:** the [Project Pitch](pitch/pitch.md) explains what Ludus is; the
[PSAA](plans/psaa.md) explains how it is built and assured.
