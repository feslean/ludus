# Code of Conduct

The Ludus project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Its full text applies to all project spaces — the repository, issues,
pull requests, discussions and any other channel the project operates — and to anyone
representing the project in public spaces.

## Reporting

Instances of abusive, harassing or otherwise unacceptable behavior may be reported to the
project lead listed in [MAINTAINERS.md](MAINTAINERS.md).

The project has not yet set up a dedicated private address for conduct reports (open item
OI-008 in the [SAS v0.1.0](docs/releases/v0.1.0/sas.md)). Until it has, contact the project
lead through the contact details on their GitHub profile, or open an issue that asks for a
private contact **without** describing the incident.

All reports are reviewed and investigated promptly and fairly. The project lead respects the
privacy and security of the reporter of any incident.

## Enforcement

The project lead applies the enforcement guidelines of the Contributor Covenant 2.1
(correction, warning, temporary ban, permanent ban). If a report concerns the project lead,
it may be addressed to any other maintainer listed in [MAINTAINERS.md](MAINTAINERS.md).
